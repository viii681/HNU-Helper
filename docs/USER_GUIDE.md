# 海大通 (HnuTong) · 主要功能与使用说明

**海大通**是面向**海南大学（Hainan University）**全体本科生与研究生打造的跨平台 Web/PWA 校园一体化服务系统，支持手机浏览器「添加到主屏幕」沉浸式全屏使用，亦支持平板与电脑桌面宽屏双栏工作台浏览。

---

## 一、快速上手（首次绑定海南大学学号）

1. 打开系统网址，点击底部导航栏右侧的 **「我的」**。
2. 在「绑定海南大学强智教务系统」卡片中：
   - 输入**海南大学学号**（如 `2024300128`）与**统一身份认证密码**（与网上办事大厅 `ehall.hainanu.edu.cn` 相同；若忘记密码可点击输入框右上角「忘记密码？」直达海大 `authserver` 找回页）。
   - 若页面展示图形验证码，输入右侧验证码（点击图片可刷新）。
   - *本地演示模式说明*：当服务端配置 `enable_demo_account: true` 时，可点击 **「体验账号」** 一键填入海大沙箱数据（学号 `2024300128`，密码 `hnu123456`）体验全部完整交互。
3. 点击 **「登录并同步海大教务」**，系统将在数秒内拉取并缓存您的本学期 11 节课表、历年成绩绩点、期末考场安排与专业培养方案，此后即使遇到弱网或教务系统临时维护，打开页面也能秒级加载本地离线快照。

## 二、五大核心模块使用指南

### 1. 课表（海大 11 节作息 + 截止圆点内嵌 + 空教室 + 校历订阅）
- **周视图 / 日视图**：
  - 手机端支持手指左右划动切换上/下一教学周；点击顶部 `第 N 周 ▾` 可跳选任意周次，或切换翻阅**历史学期课表**。
  - 课表日历表头直接汇总显示当日**待交作业圆点**、**在线考试菱形**与**学校排考「考」字色带**，点击表头即可展开当天截止任务清单。
  - 点击任意课程色块可查看完整任课教师、教室、周次，支持**自定义更换课程颜色**、**仅隐藏单节**或**隐藏整门课**。
- **五校区空教室查询**：
  - 点击顶栏「空教室」，选择日期、校区（海甸校区 / 儋州校区 / 观澜湖校区 / 崖州湾科教园 / 城西教学点）、教学楼与空闲节次（支持一键选上午 1–4 节、下午 5–8 节、晚上 9–11 节），实时查询无课自习教室与座位数。
- **海大校历与系统日历订阅 (.ics)**：
  - 点击顶栏「校历」，查看 2026–2027 学年秋季/春季学期关键时间节点。
  - 点击 **「复制订阅链接」**，在 iPhone「设置 → 日历 → 账户 → 添加已订阅的日历」或华为鸿蒙/小米/Outlook 日历中粘贴该地址，即可在手机锁屏桌面小组件中实时看到下一节课与作业截止提醒。

### 2. 学习（外部课程平台 + 学校教务学业）
- **超星学习通（只读安全扫描）**：
  - 绑定学习通手机号后，系统自动以您本学期海大教务课表作为白名单扫描在修课程作业、随堂测验与在线考试（自动跳过往年结课旧课，减轻上游压力）。
  - 支持 **「随堂练习快查」**（上课期间快速检查老师刚刚发出的随堂测验或签到）、**「通知收件箱」** 以及手动 **「标为已交」**（标记后课表头部的截止圆点同步消去）。
- **中国大学 MOOC**：
  - 在电脑浏览器登录 `icourse163.org` 后复制请求 Cookie 粘贴绑定，自动汇总国家级一流本科课程的单元测验与互评作业截止时间。
- **雨课堂 / 智慧树 / 知到（预留扩展槽位）**：
  - 支持将跨校共享课或雨课堂绑定账号、口令与看课备忘统一存入 AES-256-GCM 加密保险箱，并提供一键直达官方学习端入口。
- **考试 / 成绩 / 学分**：
  - **考试**：支持切换学期查看期末考场教学楼、房间、座位号与倒计时，内置**强智教务选课/评教/重修通道开放探测**。
  - **成绩**：自动计算加权平均学分绩点（GPA），绘制历年各学期 GPA 变化柱状图，支持按学期筛选与课程搜索。
  - **学分**：对照海南大学专业培养方案，自动将课程归类为「已通过 / 本学期在修 / 待修缺口」，清晰展示距离毕业要求还差多少学分。

### 3. 海大指南（多校区生存与开源学习导航）
- 收录海南大学「五校区 + 十七书院」办事分工说明、海甸校区教学楼速查、**海南回南天防潮防霉指南**、**台风橙/红色预警停课规则**、校内电动车通行充电规范，以及海大课程攻略共享计划与飞跃手册直达链接，支持关键词即时检索。

### 4. 校园（最近考试倒计时 + 今日课程速览 + 海大服务/WebVPN + 台风预警公告）
- **最近考试倒计时卡片**：
  - 自动从已同步的排考安排中提取距离最近的一场考试，醒目展示剩余天数、课程名、具体考试时间、考场教室与座位号（考前 7 天内自动高亮提醒），点击一键直达完整排考页。
- **今日课程速览卡片**：
  - 实时统计当日大节课数并提示正在上课或下一节课的上课时间与地点；若当日无课，一键跳转五校区空闲自习教室查询。
- **校内服务与 WebVPN 导航**：
  - 针对海南大学网络特性清晰区分 **「公网直连服务」**（强智教务、图书馆、CARSI 校外知网直连、智课平台、校园百事通、`@hainanu.edu.cn` 教育邮箱自助开通）与 **「校园网 / WebVPN 内部系统」**（网上服务大厅 `ehall`、正版软件平台），提供校外免插件一键登录 `webvpn.hainanu.edu.cn` 入口及微信「海大 e 卡」办理指引。
- **海南大学通知公告**：
  - 自动聚合本科生院（重要通知、教务运转、学籍管理、教务动态）及海大主站、海大讲坛 6 大官方源，自动将**台风防汛、停课调休、停水停电**归入「影响出行」置顶警示，点击任意通知即可提取 `vsb_content` 正文摘要与时间地点。

### 5. 我的（学籍档案 + 11 节作息预设 + 自定义加课 + 隐私安全）
- 点击顶部身份名片可展开完整 14 项海南大学学籍档案（学院、书院、专业方向、行政班、预计毕业日期等）。
- 支持一键切换 **「海甸/儋州/观澜湖标准作息（07:40起）」** 与 **「三亚崖州湾科教园协同作息（08:00起）」**，亦支持可视化网格点选添加自定义课程、管理全部 7 个平台连接及提交自动脱敏问题反馈。
